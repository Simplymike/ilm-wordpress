## 🐛 Типичные проблемы и решения

### Проблема: Гамбургер меню не открывается

**Решение:**
1. Проверьте консоль DevTools (F12 → Console)
2. Нет ошибок с `mobile-menu.js`?
3. Перезагрузите страницу Ctrl+R
4. Очистите кэш: Ctrl+Shift+Delete

### Проблема: Текст не читаемый на мобильных

**Решение:**
1. Проверьте font-size в Inspector
2. На мобильных минимум 16px для тела текста
3. Заголовки должны быть больше

### Проблема: Изображения обрезаны

**Решение:**
1. Проверьте aspect-ratio в CSS
2. Значение должно быть 16/9 для карточек новостей
3. Используйте `object-fit: cover`

### Проблема: Меню открывается но подменю не раскрывается

**Решение:**
1. Проверьте JavaScript в консоли
2. Убедитесь что mobile-menu.js загружен
3. Перезагрузите страницу

### Проблема: Performance Score низкий

**Решение:**
1. Оптимизируйте изображения (меньше размер файла)
2. Включите gzip сжатие
3. Используйте CDN для изображений
4. Минифицируйте CSS/JS

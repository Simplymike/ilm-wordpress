# 🔐 SSL Certificate Setup для izoralm.ru

**Статус:** Нужен бесплатный SSL сертификат  
**Решение:** Let's Encrypt сертификат для ручной загрузки

---

## 🎯 Ваша панель управления: Ручная загрузка сертификата

Вы видите интерфейс "**Установка сертификата**" с полями для:
- Сертификат (certificate)
- Промежуточный сертификат 
- Приватный ключ (private key)

Это означает что нужно **получить сертификат от Let's Encrypt**, а затем загрузить его в эту панель.

### 🚀 Получить бесплатный сертификат

**Способ 1: Через SSH (если есть доступ)**

Это самый надежный способ:

```bash
# 1. Подключитесь по SSH к серверу:
ssh izo2414076@izoralm.ru

# 2. Установите Certbot (если не установлен)
sudo apt-get update
sudo apt-get install certbot python3-certbot-apache -y

# 3. Получите сертификат
sudo certbot certonly --webroot -w /home/izo2414076/izoralm.ru/docs \
  -d izoralm.ru -d www.izoralm.ru

# 4. Выберите Email verification

# Файлы будут в папке: /etc/letsencrypt/live/izoralm.ru/

# 5. Скопируйте файлы на локальный компьютер:
scp izo2414076@izoralm.ru:/etc/letsencrypt/live/izoralm.ru/fullchain.pem ./certificate.crt
scp izo2414076@izoralm.ru:/etc/letsencrypt/live/izoralm.ru/privkey.pem ./private.key
```

**Способ 2: Через SSL.com (если нет SSH)**

1. Перейдите: https://www.ssl.com/ssl-certificate/
2. Выберите **Free SSL Certificate**
3. Введите домен: `izoralm.ru`
4. Пройдите Email Verification
5. Скачайте сертификаты

**Способ 3: Через sslforfree.com**

1. Перейдите: https://www.sslforfree.com/
2. Введите домен: `izoralm.ru`
3. Выберите проверку по файлам (File Upload)
4. Следуйте инструкциям

### 📋 Загрузить в панель nic.ru

1. Откройте этот интерфейс "Установка сертификата" на nic.ru
2. В поле **Сертификат**:
   - Нажмите **"Загрузить файл"**
   - Выберите файл `certificate.crt`
3. В поле **Промежуточный сертификат**:
   - Нажмите **"+ Добавить промежуточный сертификат"**
   - Выберите файл `ca_bundle.crt`
4. В поле **Приватный ключ**:
   - Нажмите **"Загрузить файл"**
   - Выберите файл `private.key`
5. Пароль: оставьте пустым (сертификат не защищён паролем)
6. Нажмите **"Установить"** ✅

**Готово!** Сертификат установлен.

## 🔄 Автоматическое обновление сертификата

**Важно:** Let's Encrypt сертификаты действуют **90 дней**. Нужно обновлять или переизбираться за 30 дней до истечения.

### Способ 1: Автоматизация через SSH (рекомендуется)

Если у вас есть SSH доступ:

```bash
# Подключитесь по SSH к серверу:
ssh izo2414076@izoralm.ru

# 1. Установите Certbot (если не установлен)
sudo apt-get install certbot

# 2. Получите сертификат напрямую для домена
sudo certbot certonly --webroot -w /home/izo2414076/izoralm.ru/docs \
  -d izoralm.ru -d www.izoralm.ru

# 3. Создайте автоматическое обновление (cron)
sudo crontab -e

# Добавьте эту строку:
0 0 * * * certbot renew --quiet && systemctl reload apache2

# Это будет проверять сертификат каждый день в полночь
# и автоматически обновлять за 30 дней до истечения
```

**Результат:** Сертификат обновляется автоматически каждые 90 дней ✓

### Способ 2: Вручную через ZeroSSL

Если нет SSH доступа:

1. Раз в 2-3 месяца заходите на https://zerossl.com/
2. Получайте новый сертификат
3. Загружайте в панель nic.ru

**Совет:** Поставьте напоминание в календарь на день 60 после установки.

## 🔗 WordPress: Принудительно перейти на HTTPS

После установки SSL сертификата, обновите WordPress:

#### В админке WordPress:
1. Перейдите: **Параметры** → **Общие**
2. Измените оба значения с `http://` на `https://`:
   - **Адрес WordPress (URL):** `https://izoralm.ru`
   - **Адрес сайта (URL):** `https://izoralm.ru`
3. **Сохраните изменения**

#### Принудительное перенаправление HTTP → HTTPS

Добавьте в `.htaccess` (в корне сайта):
```apache
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>
```

## 🛠️ Troubleshooting

| Проблема | Решение |
|----------|---------|
| "Failed to verify domain ownership" | Убедитесь что DNS правильно указывает на сервер |
| Сертификат не обновляется | Проверьте что AutoSSL включен и включено обновление |
| Mixed content warning | Обновите все ссылки на изображения в WordPress (http → https) |
| Браузер показывает красное предупреждение | Подождите 15-20 минут, пока сертификат распространится |

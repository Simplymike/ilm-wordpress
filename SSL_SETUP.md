# 🔐 SSL Certificate Setup для izoralm.ru

**Статус:** Нужен бесплатный автоматический SSL сертификат  
**Решение:** Let's Encrypt + AutoSSL на nic.ru

---

## ✅ Вариант 1: AutoSSL в cPanel (рекомендуется)

### Если у вас cPanel (обычно на nic.ru)

#### Шаг 1: Откройте cPanel
```
https://izoralm.ru:2083
или
https://[ваш-ip]:2083
```

#### Шаг 2: Найдите AutoSSL
- Перейдите в **Home** → **SSL/TLS Status**
- Или поиск **"AutoSSL"** / **"SSL/TLS Status"**

#### Шаг 3: Убедитесь что включен AutoSSL
- Нажмите **Manage AutoSSL**
- Убедитесь что **AutoSSL включен** ✓
- Поставьте галочку **"Let's Encrypt"** в качестве провайдера

#### Шаг 4: Генерируем сертификат
- Нажмите **Issue SSL Certificate** (или **Generate**)
- cPanel автоматически создаст бесплатный Let's Encrypt сертификат
- Сертификат будет действителен **90 дней**

#### Шаг 5: Автоматическое обновление
- AutoSSL **автоматически обновляет** сертификаты за 30 дней до истечения
- Вы ничего делать не нужно! ✓

### ✅ Результат:
```
✓ HTTPS включен на https://izoralm.ru
✓ Сертификат автоматически обновляется
✓ Браузер показывает зелёный замок 🔒
```

## 🔄 Автоматическое обновление (универсально)

### Если панель не имеет встроенного AutoSSL

Можно настроить через SSH + Cron + Certbot:

```bash
# 1. Установите Certbot (если не установлен)
# На сервер через SSH:
sudo apt-get install certbot python3-certbot-apache

# 2. Получите сертификат
sudo certbot certonly --webroot -w /home/izo2414076/izoralm.ru/docs -d izoralm.ru -d www.izoralm.ru

# 3. Создайте автоматическое обновление (cron)
# Запустите: crontab -e
# Добавьте строку:
0 0 * * * certbot renew --quiet

# Это будет проверять сертификат каждый день в полночь
# и автоматически обновлять за 30 дней до истечения
```

## 🔗 WordPress: Принудительно перейти на HTTPS

После установки SSL сертификата, обновите WordPress:

#### В админке WordPress:
1. Перейдите: **Параметры** → **Общие**
2. Измените оба значения с `http://` на `https://`:
   - **Адрес WordPress (URL):** `https://izoralm.ru`
   - **Адрес сайта (URL):** `https://izoralm.ru`
3. **Сохраните изменения**

#### Принудительное перенаправление HTTP → HTTPS

Добавьте в `.htaccess` (в корне сайта):
```apache
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>
```

## 🛠️ Troubleshooting

| Проблема | Решение |
|----------|---------|
| "Failed to verify domain ownership" | Убедитесь что DNS правильно указывает на сервер |
| Сертификат не обновляется | Проверьте что AutoSSL включен и включено обновление |
| Mixed content warning | Обновите все ссылки на изображения в WordPress (http → https) |
| Браузер показывает красное предупреждение | Подождите 15-20 минут, пока сертификат распространится |

# ИжораЛитМаш на WordPress

Локальный проект использует WordPress 7.1.4, PHP 8.3 и MariaDB 10.11. Сайт доступен только на этом компьютере. Тема находится в `wp-content/themes/ilm-preview`. Изменения её файлов видны в Docker сразу.

## Запуск

На этом компьютере файл `.env` уже создан, а база и файлы сайта хранятся в Docker. Из этой папки запусти:

```powershell
docker compose up -d
```

Сайт открывается на [127.0.0.1:8080](http://127.0.0.1:8080/), админка — на [127.0.0.1:8080/wp-admin/](http://127.0.0.1:8080/wp-admin/). Для остановки используй `docker compose stop`.

## Развёртывание из Git

Корнем репозитория служит эта папка (`wordpress-local`). После клонирования скопируй `.env.example` в `.env` и задай свои пароли для локальной MariaDB. Если порт 8080 занят, измени `WP_PORT` перед первым запуском.

Для восстановления копии сайта помести полученные отдельно `site.sql` и `wp-content.tar.gz` в папку `private`. Затем выполни `./restore.ps1` в PowerShell. Скрипт рассчитан на пустую базу и переводит ссылки с тестового домена на локальный адрес. Для чистой установки достаточно `docker compose up -d` и мастера WordPress в браузере.

Git хранит тему, конфигурацию Docker и сценарий восстановления. Пароли, дампы и загруженные через админку медиа остаются локально. Изменения в записях и настройках хранятся в базе WordPress, поэтому для их переноса нужен новый снимок. Отправка писем отключена локальным плагином.

## Старый сайт

Конфигурация и данные UMI.CMS находятся уровнем выше. Если понадобится временно запустить старую копию на том же порту, сначала останови WordPress командой `docker compose stop` из этой папки, затем запусти Compose из папки `ILM_web`.
